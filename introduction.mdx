DTS (Dialogue Translation System) is an open-source, AI-powered tool for the bulk automated translation of dialogue strings in GameMaker-based video games — specifically games built on Toby Fox's engine, such as **Undertale** and **Deltarune**. Rather than requiring you to manually edit hundreds or thousands of dialogue entries, DTS orchestrates a full pipeline: extract strings from a `data.win` game file, translate them through an AI provider of your choice, normalize the output, and inject the results back — all without touching a single string by hand.

## What DTS Does

DTS automates the entire localization workflow for GameMaker dialogue through four stages:

1. **Extract** — Pull raw dialogue strings from `strings.json` (produced from `data.win` via UndertaleModTool) into a translation-ready input file (`lang_input.json`).
2. **Translate** — Send dialogue chunks to an AI provider in batches and collect responses into `lang_es_out.json`.
3. **Normalize** — Post-process AI output to fix encoding artifacts, strip invalid characters, and preserve in-game command tokens, producing `lang_es_normalize.json`.
4. **Inject** — Apply the cleaned translations back to the original string table, producing `strings_es.json` ready for reimport via UMT.

## Two Interfaces

DTS ships as a single `dts` command that automatically switches between modes depending on how you invoke it:

- **CLI (Click)** — Pass any argument and DTS runs as a fully scriptable command-line tool. Ideal for automation, CI pipelines, and headless environments.
- **GUI (ttkbootstrap)** — Run `dts` with no arguments and a desktop GUI launches, giving you a visual project manager, progress indicators, and point-and-click configuration.

## AI Providers

DTS integrates with seven AI providers out of the box, from commercial cloud APIs to fully local inference:

| Provider | Type | Notes |
|---|---|---|
| **Gemini** | Cloud | Google AI; default provider |
| **OpenAI** | Cloud | GPT-4o and GPT-4o-mini |
| **Anthropic** | Cloud | Claude 3.5 Sonnet and Haiku |
| **Groq** | Cloud | OpenAI-compatible API |
| **DeepInfra** | Cloud | OpenAI-compatible API |
| **Together AI** | Cloud | OpenAI-compatible API |
| **Ollama** | Local | Fully offline; runs on your machine |

## Integration with UndertaleModTool

DTS relies on **UndertaleModTool (UMT)** — an external, open-source utility licensed under GPLv3 — to extract `strings.json` from a `data.win` binary and to reimport translated strings. DTS does **not** bundle UMT; it invokes it externally. You can point DTS to an existing UMT installation via the settings, or download it automatically from within the GUI.
